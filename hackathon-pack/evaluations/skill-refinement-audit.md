## Significant corrections from real failures

1. **Fidelity before machinery:** the early creative contract encouraged save/export/audio work beyond the user's visual aim. The revised entrypoint classifies the requested fidelity first and treats a small representative slice as enough for a skill experiment.
2. **Middle mobile composition:** reversible animation and good endpoints hid overlap/empty travel. Intermediate subject scale/crop, type collision and the next useful view are now explicit acceptance criteria. Before/after frames are in creative-motion-v4/.
3. **Draft ownership:** browsing another specimen silently retargeted unfinished text. Owner remains stable while browsing; explicit form choices can retarget. Fresh retest saved Papaver after browsing Lilium.
4. **Rejected finance decisions:** a balanced proposal with the same rejected hash could pass with a replaced approval. Trusted scoped prior-decision history is now required and exact rejected snapshots remain held; revised snapshots need fresh independent approval.
5. **Actor/build identity:** a bounded Apify envelope did not verify the expected Actor/build in returned run metadata. Correct REST numeric selector versus opaque-ID handling is now enforced; mismatches hold before dataset reads or any replacement run.
6. **Event/source gaps:** proprietary Visa APIs are not provided; Hyphenate's enterprise may be independently built. Visa weights, SpaceXSI tooling, sponsor amounts and the Sunday cutoff contain explicit conflicting sources. No invented reconciliation.
