# Primary-source creative-web atlas

Verified 2026-10-23. These are study references, not assets to copy. Official case-study descriptions support factual summaries; **transfer** notes are our design interpretation. Browser-rendered composition was additionally inspected for Active Theory. Source accessibility and reduced-motion support were not audited; proposed fallbacks below are recommendations, not claims about the originals.

## Official implementation references

- [React Three Fiber — scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance): use demand rendering for scenes that can settle; request invalidation after imperative changes; reuse geometry/materials; instance repeated objects. Hardware cost informs the scene budget, not a universal FPS promise.
- [React Three Fiber — performance pitfalls](https://r3f.docs.pmnd.rs/advanced/pitfalls): avoid React state updates in fast frame loops; use frame deltas; avoid needless remounts and resource compilation.
- [GSAP — React integration](https://gsap.com/resources/React/): scope animations with `useGSAP`, cleanup through context, use `revertOnUpdate` when required, and make later event-created animations context-safe. Do not leave orphaned timelines after view switches.
