# Mobile / game reference atlas

Researched 2026-10-23. Select a few sources suited to the current screen and assign each a specific relationship to study. Revisit the actual primary imagery before claiming a current comparison. This is an index, not a style ranking or an asset library.

Navigate by need: care/character staging → 01–02, 07, 09, 12; world/map composition → 15–18; contemporary drawn art → the final section; Flutter/animation mechanics → 32–34; matched-size professional comparisons → [mobile-comparison-gates.md](mobile-comparison-gates.md). Read only the relevant entries and primary examples.

**V**: source imagery visually inspected during research. **R**: primary page or original instructions read. **Q**: verified further-research destination; no inspected interaction or screen composition claimed. Static screenshots, promotional composites and documentation do not establish live press feedback, motion or performance. Reference artwork remains its creators' property; author original production assets.


The index mixes visual examples, original design explanations, and production documentation. It is not a ranking. Q entries are research leads, not evidence-backed quality endorsements.

## Contemporary drawn direction — eight additional primary sources

Use when the brief asks for expressive, hand-designed illustration with a clean modern finish. Authored proportions, confident contour and color hierarchy matter more than simulated wear. Pok Pok, Toca and Sago imagery was subsequently inspected; the studio case studies below were read, not motion-tested.


| Source | Evidence and decision to learn |
|---|---|
| [Pok Pok — original press kit](https://playpokpok.com/press/press-kit/) and [official playroom](https://playpokpok.com/) | **V/R.** Developer describes hand-drawn animation, handcrafted toys, and open-ended play rather than prizes. Study a digital toy's shape, physical action, and response together. Its no-language preschool product model is context-specific, not a reason to remove useful labels from every game. The press kit contains phone/tablet screenshot sections and official toy trailers. |
| [Toca Boca World — original game page](https://www.tocaboca.com/toca-boca-world) | **V/R.** Official feature imagery includes map, Character Creator, Home Designer, and play scenes. Compare the different composition for each tool. Exact primary image lead: [Character Creator](https://www.datocms-assets.com/113033/1709024979-pic2.png?auto=format&fit=crop&w=1440). Study authored proportions and category/result relationships; do not copy characters, props, or branding. |
| [Sago Mini World — original game page](https://sagomini.com/world/) | **V/R.** Distinct creation, exploration, care, and construction activities share a character universe. Exact primary image lead: [Hat Maker gameplay graphic](https://sagomini.com/workspace/uploads/entities/card-generic/creative-1592837399.svg). Study how illustrated objects become manipulable tools and how a character remains readable during making; a promotional image does not prove the live input behavior. |
| [Headspace — official illustration guidelines](https://live.standards.site/headspace/illustration) | **R, through indexed original page text.** Recommends simple palettes, flat fills without outlines, thoughtful metaphors, and dynamic scale; depth can come from shadow and scale contrast. This directly challenges “drawn means rough contour.” Use its design logic, not its face library, dot, palette, or numerical color limit as a universal rule. |
| [ITAL/C — original Headspace rebrand case study](https://italic-studio.com/projects/headspace-rebrand/) | **R.** Original designers describe a simpler, bolder, more colorful identity with a simplified illustration library and custom type. Useful for evolving warmth into a contemporary, broader visual system without discarding identity. The project also includes texture; its lesson is hierarchy and simplification, not a blanket texture prohibition. |
| [Meister — original Headspace animation case study](https://meister.tv/work/headspace) | **R.** Production partner emphasizes simple shapes, small purposeful movement, and emotional specificity; describes bold close crops for an outdoor campaign. Learn how posture, eye/brow change, and timing make a minimal shape act. Campaign compositions are not ready-made mobile UI; translate the relationship to an action response. |
| [BUCK — original Headspace film case study](https://buck.co/work/headspace) | **R, indexed original page text; direct fetch timed out.** Original studio describes balancing shape language and storytelling while giving each shape room to serve a narrative. Use for staging and restraint, not extra effects. This is film/character work, not evidence of touch-target usability. |
| [Nathan Godding — original Headspace guidelines project](https://nathangodding.com/HEADSPACE-BRAND-GUIDELINES) | **R.** Designer identifies responsibility for guidelines content/assets and collaboration on accessibility standards. Study how an illustration system is documented with practical constraints across assets and layouts. It supports treating accessibility as part of authorship, rather than a late audit of decorative art. |
