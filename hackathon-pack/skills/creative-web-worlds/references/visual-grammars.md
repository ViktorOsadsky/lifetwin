# Seven visual grammars beyond a component showcase

Use for open web composition briefs. Costs are rough planning estimates for a narrow slice with simple original assets, not quality guarantees or required budgets. They exclude backend integration and production illustration. Pick a coherent grammar rather than combining every technique.

## 1. Spatial toy town · 3D or isometric 2.5D

**Layout:** one navigable stage, three recognizable landmarks, stable task ledger outside the stage. Physical distance reflects conceptual grouping. **Type:** compact sign-like destination names and a calm DOM explanation. **Material:** low-detail wood, clay, paper or painted surfaces; choose a consistent lighting/shadow direction. **Motion:** selection raises/focuses one object; deliberate camera destinations, no continuous orbit. **State:** landmark picked → details and action appear; committed state stays marked both spatially and in text. **Access:** a landmark list triggers identical actions; mobile uses a fixed camera or list; reduced motion jumps between states. **Cost:** SVG 3–6 hours; modeled Three.js scene 8–16+ hours. Inspired by Bruno Simon, Choo Choo World, Tomorrowland.

## 2. Product theater · real 3D

**Layout:** one oversized object with a persistent option rail and price/result area; explanatory sections orbit the product concept, not literal navigation. **Type:** bold functional names paired with short editorial copy; no text buried on an unreadable model surface. **Material:** a narrow palette of roughness, metal, translucent parts and intentional light. **Motion:** rotation/exploded views explain one feature or option; the object settles after input. **State:** selected variant changes both actual scene material and DOM selection; loading/error never impersonates a configured product. **Access:** DOM swatches/radios, static product render on failure, no mandatory model manipulation. **Cost:** 6–12 hours with a ready licensed model, more for original modeling. Sources: ION, Quantum Wallet. Avoid claiming a fictional concept is a real available product.

## 3. Paper chapter world · 2D / 2.5D

**Layout:** sequential full-width spreads with overlap, cutout edges, and one consistent spine; each chapter has useful information. **Type:** display and body roles follow the paper story; margins carry short annotations. **Material:** flat authored SVG shapes, two or three depth layers, restrained grain only if owned/generated appropriately. **Motion:** a fold, reveal or lateral shift connects consecutive states. **State:** chapter identity and progress are explicit, and can be revisited. **Access:** direct chapter links and complete readable article mode; motion-free view displays the final spread. **Cost:** 3–7 hours with original SVG. Source: My Little Storybook; transfer its material cohesion, not its imagery.

## 4. Kinetic type architecture · 2D

**Layout:** letters form divisions, windows and transitions across an entire composition; align meaningful content to a consistent underlying grid. **Type:** choose one expressive family/weight and one reading role; oversized type must remain comprehensible. **Material:** ink, flat color, masks, hard-edged contrast; objects are optional. **Motion:** a user-triggered type transition reveals a new content level, then yields to reading. **State:** original link name remains in the next view and focus moves logically. **Access:** semantic headings and links, redundant decorative letter copies hidden from assistive tech, immediate switch for reduced motion. **Cost:** 2–5 hours. Source: Manoela Ilic's kinetic transition. Avoid an always-moving marquee posing as a design concept.

## 5. Instrument / material laboratory · 3D or 2D

**Layout:** object-centered workbench, small grouped parameter set, persistent result and reset. **Type:** readable control labels and exact values; a strong tool identity rather than scattered cards. **Material:** one coherent shader/surface palette with only meaningful variation. **Motion:** direct response to a control; response latency matters more than elaborate entrance. **State:** changing a parameter updates an exact useful outcome and can be undone/reset; randomization discloses its seed or is clearly illustrative. **Access:** named native controls, keyboard increments, numeric entry where precision matters, static chart/summary alternative. **Cost:** 4–8 hours for a narrow 2D instrument; 8–16+ for authored shaders. Source: Blobmixer. A finance model needs domain-valid calculations behind its visual changes.

## 6. Traceable journey / evidence atlas · 2D SVG

**Layout:** route or connected field plus synchronized chapters/legend; route order encodes an actual process. **Type:** clear stage labels and supporting evidence; geography is subordinate to understanding. **Material:** drawn line, map substrate, consistent symbols and annotation hierarchy. **Motion:** route drawing and optional nested-group camera follow the active stage. **State:** current node, completed steps and unavailable branches are distinct through labels and shape as well as color. **Access:** full static route, ordered DOM list, direct step links; reduced motion changes active emphasis without a traveling camera. **Cost:** 2–5 hours for authored SVG. Source: Tom Miller's SVG map tutorial. Never make a long scroll journey the only path to the action.

## 7. Specimen editorial · 2D / optional 3D

**Layout:** disciplined caption/grid system framing organic authored objects; the contrast between playful subject and precise evidence is the identity. **Type:** hierarchy separates names, evidence, and navigation; labels have real informational jobs. **Material:** limited ink palette with irregular organisms/shapes; a single microscope/viewport motif. **Motion:** inspection enlarges one specimen and reveals data. **State:** selected object persists while details change; empty and missing evidence states are explicit. **Access:** tabular/list equivalent, magnification alternatives, no lens-only text. **Cost:** 3–6 hours for original SVG. Source: KIKK 2018. This can serve transaction anomaly exploration without turning uncertain indicators into verified fraud claims.

## Select using the actual task

For a bounded visual study, build one decisive composition and interaction before expanding art. Reserve time for rendered critique and narrow-screen repair. For a product build, simplify the scene if the useful loop breaks. Test the composition at narrow mobile and the target desktop size. Judge originality by whether the task, navigation, type and results share a concept—not by number of effects.
