# Conditional track recipes — checked 2026-10-23

The [live Hive rubric](https://hive.hackberkeley.org/prizes) is the event source. These are implementation hypotheses, not declarations of eligibility. Recheck linked docs and exact sponsor brief. No SDK snippets below are asserted current. The later [resource review routes](resource-routes.md) add verified starter-pack contracts and source conflicts; read the selected route before implementation.

| Track | Useful role and minimum proof | Hard test / condition | Official discovery starting point |
|---|---|---|---|
| Factory | Trigger a Droid SDK job inside the running product, e.g. repair a broken evidence extractor in a scoped branch; show trigger → plan → diff → tests → user review | Malicious source text cannot expand file/network scope; generated patch cannot deploy itself. Coding with Droid alone is insufficient | [Factory docs](https://docs.factory.com/) — locate current SDK reference |
| Microsoft | Production-minded agent with customer-specific task, measurable outcome, durable job and responsible action boundary | Restart mid-workflow; show no duplicated effects and one honest customer metric. Visible Hive rubric does not specify Azure requirement; verify sponsor brief | [Microsoft Foundry docs](https://learn.microsoft.com/en-us/azure/ai-foundry/) if relevant to chosen stack |
| Figma | Editable design and interaction story; a Figma Agent workflow only if actually used; show design decisions translating to working experience | Confirm each category's requirement. Screenshot of a webpage does not prove Figma Agent use; capture actual artifact and tool contribution | [Figma developer docs](https://developers.figma.com/) and official event brief linked from Hive |
| Convex | One durable reactive job/evidence/exception model shared by user and agent | Refresh and two-browser collision; authorize each query/action by tenant | [Agents](https://docs.convex.dev/agents/overview), [tool approval](https://docs.convex.dev/agents/tool-approval) |
| SpacetimeDB | Shared live state in a simulation, auction or multi-user ops room | Simultaneous revisions and disconnected client recovery; server-side validation | [Docs](https://spacetimedb.com/docs/) — current version differs from older tutorials |
| Fetch.ai | A discoverable specialized agent collaborating through the sponsor ecosystem to finish a real task | Verify discovery and invocation from the actual required surface, then validate timeout and malformed peer response | [Cal Hacks sponsor page](https://www.fetch.ai/events/calhacks-13-0), follow current starter pack |
| CRS | Sponsor sandbox data essential to the workflow, working live in demo | Only sponsor test identities; credentials and granted product collection remain an access gate. The linked MCP is described as development help, not verified live data | [Cal Hacks sandbox](https://calhacks.crscreditapi.com), [resource route](resource-routes.md#crs-live-sandbox-separate-development-helper) |
| Elastic | Search/retrieval agent over evidence on a Serverless instance using Agent Builder | Source sentence supports answer; show missing-evidence abstention and retrieval evaluation | [Agent Builder setup](https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/get-started), [programmatic access](https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/programmatic-access) |
| Cartesia | Voice central to a useful task, using Managed Agents or Sonic TTS | Barge-in, cancellation, captions / text alternative; two-minute complete-flow demo, README and code access | [Cartesia route](resource-routes.md#cartesia-choose-managed-conversation-or-speech-output) |
| Coinbase x402 | A useful paid API/evidence service or agent paying for a needed service in a test environment | Price/asset/network cap, duplicate payment, no wrong-network confirmation. Need current track PDF; don't conflate x402 with Visa checkout | [x402](https://www.x402.org/), [official repo](https://github.com/coinbase/x402) |
| Anthropic | A named community, concrete need and meaningful Claude reasoning with known failure limits | Show a working task and a vulnerable group-specific failure handled; prize was TBD | [Claude docs](https://docs.claude.com/) and event rubric |
| Bright Data | Essential live public-web evidence with normalized useful output | Blocks/slow/empty results handled live. Published rubric prohibits login/paywall scraping, non-public personal data and mocked/hardcoded demo data | [Bright Data docs](https://docs.brightdata.com/) |
| CREAO | A saved CREAO agent performs core work; use async status/results in your product | Agent ID plus run share link in README, live demo, selected Devpost track. Verify unsigned callbacks through authenticated lookup; preserve prize-source conflict | [Event pack](https://community.creao.ai/CalHacks2026), [contract route](resource-routes.md#creao-asynchronous-core-agent) |
| Capital One Nessie | Synthetic bank accounts/transactions powering a demonstrable finance workflow | Treat sandbox data as synthetic, never real balance/payment claims | [Nessie](http://api.nessieisreal.com/) — verify TLS/access/current docs before use |
| Bitdeer | Model Studio chat, embedding, reranking or image generation with measured usefulness | Account and credit request needed; choose current catalog model. Credits/hardware award does not justify training | [Getting started](https://developers.bitdeer.ai/docs/guides/getting-started), [catalog](https://developers.bitdeer.ai/docs/api/models-catalog) |
| Meta | AI essential to a specific human-connection workflow | Show two real participants or clearly labelled fixtures; consent and misuse case | Event's official category brief; verify Round 2 eligibility |
| SpaceXSI / SpaceXAI | Real space data and Cursor-built product | Starter PDF makes Grok Bot bonus; captured Hive additionally requires Imagine/Voice. Resolve conflict before adding an API dependency | [Starter PDF](https://drive.google.com/file/d/15YRK6uPOlHDAnc78oJOoUBQZ9cTHqCiL/view), [resource route](resource-routes.md#bright-data--bitdeer--mana--spacexsi) |
| Notability | Notes document genuine evolution from sketch to final build | Show relevant notes created during work, features used meaningfully; do not fabricate process history | [Notability](https://notability.com/) and event rubric |
| Mana | Material help through an in-Mana app or existing-repo work | One paragraph, one/two real shared chats/commits, demo moment. Working in-Mana app is +10 bonus; verify judge access and privacy | [Event pack](https://mana.space/a/calhacks) |
| Atlassian | A Forge app that automates team work or governs agent actions | Forge setup/access, malicious issue-data handling, non-destructive recovery; repository and max-three-minute video | [Forge route](resource-routes.md#atlassian-forge-app-doing-work-or-governing-actions) |
| Moss / Context.dev | Necessary retrieval or public-evidence layer | Evaluate freshness, missing sources and partial results. General capabilities do not establish a prize category | [Retrieval routes](resource-routes.md#moss--contextdev-retrieval-and-public-evidence) |
| Armadin, AfterQuery, Annapurna Labs | Decide only after reading the actual current challenge | Some brief/prize details TBD; do not invent tool APIs or award values | Official sponsor starter packs linked by event; confirm identity first |
