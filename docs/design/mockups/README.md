# Final mockups (Claude Design source)

These are static `.dc.html` artboards from the Claude Design canvas, at 390×844. Images point at the `3.0x/` variants in `app/assets/` (for example `app/assets/twin/bear/base/3.0x/cal_hat.png` and `app/assets/scene/3.0x/room.jpg`), so they stay sharp at mockup size. The naming rule is in `../painted-card-direction.md`, section 6. To view one, open it in a browser from this folder; the canvas `support.js` line fails harmlessly. The `<helmet>` block holds the fonts and shared styles. Renders are in `../screens/`.

The canvas itself is https://claude.ai/artifact/Smu6yoUWwhtuJCvdJsqVne (private; ask Daniel for access).
